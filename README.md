## 🏃‍♂️ Getting Started Locally

To run this project on your local machine:

1. **Clone the repository:**
    ```bash
    git clone https://github.com/Samsontesfamichael/personalportfolio.git
    cd personalportfolio
    ```

2. **Install dependencies:**
    ```bash
    npm install --legacy-peer-deps
    ```

3. **Run the development server:**
    ```bash
    npm run dev
    ```

4. **Open your browser:**
    Navigate to [http://localhost:3000](http://localhost:3000)

## 📦 Build and Deployment

This project is configured for **Static Export** to deploy on GitHub Pages.

### Build Locally
```bash
npm run build
```
This generates an `out` directory containing static HTML/CSS/JS artifacts.

### Deploy to GitHub Pages
The repository includes an automated GitHub Actions workflow (`.github/workflows/deploy.yml`) that builds and deploys the site when changes are pushed to `main`.

1. Push your changes to GitHub.
2. Ensure **Settings > Pages > Source** in your repository is set to **GitHub Actions**.
